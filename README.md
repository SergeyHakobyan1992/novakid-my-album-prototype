# My Album — Kids Area prototype

Clickable prototype for the Novakid "Lead, Student Experience" candidate task.

**Open:** https://sergeyhakobyan1992.github.io/novakid-my-album-prototype/

- A word collection ("My album") built on the Level 1 programme units and words.
- A Learning Engine sends each word to an existing Kids Area game depending on its mastery level
  (Memo Mix, Box Battle → Bubbles, Racing, Snake, Pinocchio → Quiz Corner — DOM replicas of the real games using their own art), and brings remembered words back for a refresh.
- Bottom bar: switch Child / Teacher / Parent / Learning Engine views, jump 3 days ahead, toggle sound or the engine, reset.

Fictional learner (Mia) and teacher (Ms. Anna); no backend, state is kept in the browser.
Kids Area images, fonts, music and UI sounds are loaded from Novakid's public CDN and are not part of this repository.
